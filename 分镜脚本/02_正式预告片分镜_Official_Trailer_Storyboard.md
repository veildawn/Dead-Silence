# 《死寂边境》正式预告片分镜脚本 (Official Trailer Storyboard)

> **时长**：90 秒 | **画幅比**：2.39:1 变形宽银幕  
> **结构**：三幕递进 + 尾版，节奏从慢到快，配合画面和台词的情绪升级  
> **色调**：低饱和灰黄滤镜，胶片颗粒感，明暗对比强烈  

---

# 第一幕：世界崩塌 (0:00 – 0:30)

> **节奏**：缓慢、压抑，从日常到灾难的坠落  
> **调色**：偏冷灰蓝 → 刺眼暖黄（灾难降临时色温突变）

# 第三幕：秩序的代价 (1:00 – 1:30)

> **节奏**：从压抑的蓄力到爆发性的高潮，节奏不断加速直至三连爆炸  
> **调色**：冷铁灰 → 火焰橙红（最终在火光中结束）

## 镜头 S16 — 废弃公路

| 项目 | 描述 |
|------|------|
| **时间** | 0:55 – 0:58 |
| **景别** | 远景跟拍 |
| **画面** | 灰色天空下，一条龟裂的废弃公路向地平线延伸。本走在前面，消防斧背在肩上。身后约十步远，莎拉步履蹒跚地跟着，腰间绷带已经渗出暗红色的血迹。两个渺小的身影在巨大而荒凉的景观中移动。 |
| **运镜** | 无人机侧面缓慢跟拍，保持两人在画面右三分之一处。突出环境的空旷和人的渺小。 |
| **音效** | 沉重的脚步声在碎石路面上的回响。风声。远处有一两声含混不清的喉音，暗示感染者仍在这片土地上游荡。 |
| **配乐** | 无。用沉默来承接第二幕结尾的悲伤。 |
| **情绪** | 公路片的荒凉美学。没有目的地、没有希望，只有往前走这一个选项。 |

## 镜头 S17 — 道德的代价

| 项目 | 描述 |
|------|------|
| **时间** | 0:58 – 1:01 |
| **景别** | 中景 → 特写 |
| **画面** | 夜晚的涵洞营地。微弱的帐篷灯光。本蹲在另一群熟睡的幸存者旁边，手伸进一个帆布袋中，缓缓取出一个药盒（抗生素）。他的动作极其轻缓，像一个职业小偷。他的脸在昏暗中半隐半现——表情不是冷酷，是痛苦的自厌。 |
| **运镜** | 从营地远景缓慢推近至本偷药的行为特写。最后切到他的面部大特写——瞳孔中映出帐篷灯的微光。 |
| **画外音** | **莎拉（虚弱的、带着怀疑的）："药……你从哪找到的？"** 本沉默。 |
| **音效** | 帐篷布在风中拍打的声音。熟睡者的呼吸声。本手指碰到药盒的轻微响声在寂静中被放大。 |
| **配乐** | 一根独奏大提琴拉出不和谐的颤音，像良心在挣扎。 |
| **情绪** | 本从"救人者"变成了"掠夺者"。他为了救一个人而伤害了其他人——而莎拉的问题是一把无声的刀。 |

## 镜头 S18 — 帕雷德斯镇的警告

| 项目 | 描述 |
|------|------|
| **时间** | 1:01 – 1:05 |
| **景别** | 中景 → 特写 |
| **画面** | 白天。一个小镇的主街道。二十具被处决的尸体整齐排列在路边——不是感染者，而是普通人。他们被射杀后像木材一样被码放。街道尽头竖着一块手写木牌。镜头缓缓推近至木牌特写：**"THE WEAK ENDANGER THE STRONG. — CAMP DAWN"** |
| **运镜** | 缓慢推近的轨道镜头。从远景看到尸体排列 → 中景看到他们是普通人（有的穿着家居服）→ 特写停在木牌上。整个镜头保持冷静克制的节奏，让恐怖自己说话。 |
| **音效** | 不和谐的低频嗡鸣，像电力设备过载的声音。苍蝇的嗡嗡声在远处盘旋。 |
| **配乐** | 低频嗡鸣即配乐——制造生理不适。 |
| **情绪** | 触目惊心。这不是丧尸造成的——是人类的"秩序"造成的。木牌上的话让这一切更加恐怖。 |

## 镜头 S19 — 黎明营地大门

| 项目 | 描述 |
|------|------|
| **时间** | 1:05 – 1:09 |
| **景别** | 远景 → 中景 |
| **画面** | 巨大的工业金属门缓缓向两侧打开。门内是黎明营地——阳光从门缝中射出，形成耀眼的逆光。将军的剪影出现在瞭望塔平台上，整齐的军装轮廓笔直如刀。他的声音在广播系统中回荡，冰冷而权威。 |
| **运镜** | 从本和莎拉的背影（前景虚焦）向营地大门拍摄。门打开时光线涌入，造成 2 秒的过曝过渡。然后切到将军的逆光低角度仰拍。 |

| **情绪** | 天堂之门还是地狱之门？过曝的光线暗示这个"希望"是虚假的。 |

## 镜头 S21 — 反抗宣言

| 项目 | 描述 |
|------|------|

| **景别** | 中景 → 大特写 |
| **画面** | 本站在营地某处的阴影中。面前是一卷引火绳和打火石工具。他低头看着手中的打火石，火光映在他的瞳孔中——但这一次不是被动的火光倒影（如先导预告片 S04），而是他即将点燃的火。他抬头直视镜头。 |

| **情绪** | 全预告片最重要的台词。一个消防员的全部职业信仰在这一刻被亲手点燃。这是他最大的牺牲——不是生命，而是身份。 |

## 镜头 S22 — 三连爆炸

| 项目 | 描述 |
|------|------|
| **时间** | 1:17 – 1:21 |
| **景别** | 远景 (正面 / 侧面交替) |
| **画面** | **三声递进的爆炸，每次比前一次更大：** |
| | **第一爆**（1s）：营地边缘的小型燃料桶炸裂，橙色火球腾空约三米。 |
| | **第二爆**（1s）：连锁引爆中型储油罐。冲击波可见地掀起周围的沙土和碎片。守卫被气浪推倒。 |
| | **第三爆**（2s）：主油罐殉爆——冲天火球如蘑菇云升起，高度超过瞭望塔。整个营地在火光中变成剪影。地平线上，无数感染者的身影被火光照亮——尸潮从四面八方涌来。 |
| **运镜** | 第一爆：中景侧面。第二爆：远景正面。第三爆：极远景，配合冲击波画面震颤效果。每次爆炸切换机位，制造越来越大的视觉冲击。 |
| **音效** | 三声递进的爆炸——低沉 → 中等 → 震耳欲聋。第三爆后有持续数秒的低频余震嗡鸣。 |
| **配乐** | 全管弦乐齐奏在第三爆达到顶点。 |
| **情绪** | 视觉高潮。消防员放的这把火，要烧掉的不只是营地——是整个虚假的秩序。 |

## 镜头 S23 — 终极搏斗

| 项目 | 描述 |
|------|------|
| **时间** | 1:21 – 1:25 |
| **景别** | 中近景 |
| **画面** | 燃烧的工厂平台顶层。火焰从脚下的缝隙中窜出。将军和本扭打在一起——两人的身影在火光中化为橙红色的剪影。将军试图用手枪瞄准本，本用消防斧格挡。金属碰撞迸出火星。平台钢梁断裂——将军脚下的地面塌陷。他试图抓住边缘，手指在发热的金属上滑动。最终——坠落，消失在火海中。 |
| **运镜** | 手持贴身跟拍，摄影机在两人之间来回切换。将军坠落瞬间切为俯拍——看他的身影在火焰中缩小消失。 |
| **音效** | 金属断裂声。消防斧与手枪碰撞的尖锐金属声。将军坠落时的风声和最后的喊叫。 |
| **配乐** | 紧张的弦乐和打击乐交织。将军坠落瞬间——一声定音鼓的低沉终结音。 |
| **情绪** | 最终对决。不是关于谁更强，而是关于哪一种"秩序"值得存在。 |

| **情绪** | 不是胜利——是突围。他们活下来了，但前方依然是未知。 |

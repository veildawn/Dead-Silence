# 《死寂边境》(Dead Frontier)

本仓库收录十集短剧《死寂边境》的项目资料。英文标题为 Dead Frontier。类型是废土 / 丧尸 / 人性生存 / 动作，背景设定在美国西部，核心关键词为死寂、背叛、救赎、消防斧。文稿按编号文件与两个目录编排：项目概览、角色设定、十集大纲、海报提示词、预告片描述，以及分镜脚本和各集详细剧情。

- [02_角色设定.md](02_角色设定.md) — 本·卡特、莎拉·詹金斯、刀疤·瑞克、弗兰克·米勒与将军的定位、定妆和生成提示词。
- [03_剧情大纲.md](03_剧情大纲.md) — 十集三幕大纲：从爆发与避难，到超市沦陷、黎明营地与火海结局。
- [04_电影海报提示词.md](04_电影海报提示词.md) — 五主角阶梯式金字塔主视觉海报提示词，以及敏感词的安全替代写法。
